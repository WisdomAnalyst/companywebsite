# HTML Contact Form Assignment

This project implements a contact form for a company website with client-side validation, POST method submission, and GET method preview functionality.

## Features

- **HTML Form** with name, email, phone, message, contact method (radio), and inquiry type (dropdown)
- **Client-side validation** for required fields, email format, and phone number (10 digits)
- **Preview feature** using GET method to display entered data before submission
- **Responsive design** for various screen sizes

## Project Structure

- `src/` - Contains all source code files
  - `index.html` - Main HTML file
  - `css/styles.css` - CSS styling
  - `js/validation.js` - JavaScript for validation and preview
- `assets/` - Static assets
- `docs/` - Documentation and submission materials

## Setup

1. Clone the repository
2. Open `src/index.html` in a web browser
3. Test the form functionality

## Validation Rules

- All fields are required
- Email must be in proper format (user@domain.com)
- Phone number must contain exactly 10 digits
